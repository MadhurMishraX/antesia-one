# Contributing to Antesia

Thank you for your interest in contributing to Antesia.

Antesia is an educational technology project focused on structured learning, assignment management, gamified progress, analytics, and teacher-student collaboration.

## License of Contributions

By submitting a contribution to this repository, you agree that your contribution will be licensed under the same license as this project:

Apache License 2.0

This means your contribution may be used, modified, distributed, and included in future versions of Antesia under the Apache License 2.0.

## Public Repository and Private Development

This public repository represents the open-source/community version of Antesia.

The project maintainer may also maintain separate private, experimental, commercial, or school-deployment versions of Antesia. Contributions submitted to this public repository do not give contributors ownership or control over those separate private versions.

## What You Can Contribute

You may contribute:

- Bug fixes
- UI improvements
- Documentation improvements
- Accessibility improvements
- Small feature improvements
- Security suggestions
- Code quality improvements

## What Not to Add Without Discussion

Please do not submit large architectural changes, database redesigns, authentication changes, AI features, or major product features without opening an issue first.

## Code Quality

Before submitting a pull request, please make sure:

- The code is readable and properly named.
- The change does not break existing student, teacher, or admin flows.
- Sensitive data, API keys, passwords, tokens, or private credentials are not included.
- UI changes stay consistent with the Antesia design language.
- The change is useful for the educational purpose of the project.

## Pull Request Rules

When opening a pull request, include:

- What problem it solves
- What files were changed
- Screenshots, if the UI was changed
- Any known limitations

## Security Issues

Please do not publicly post serious security vulnerabilities in issues.

If you discover a security problem, contact the maintainer privately first.

## Project Direction

The maintainer has final decision-making authority over what is accepted into the project.

Not every contribution will be merged. Contributions may be declined if they do not match the direction, quality, design, or educational purpose of Antesia.
